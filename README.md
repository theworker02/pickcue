# pickcue

Pick encode/decode helpers for cue payloads in pipelines.

**Site:** https://theworker02.github.io/pickcue/

## Install / run

```bash
git clone https://github.com/theworker02/pickcue.git
cd pickcue
node src/cli.js
node --test
```
